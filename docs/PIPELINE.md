# IntegrateProtRNA — Case B analysis pipeline

RNA-seq + quantitative proteomics, 2 treatments × 4 timepoints × 3 replicates,
**24 independent samples per layer** — the two layers are measured on *different*
biological material (Case B, unmatched).

## The one constraint that shapes everything

RNA and protein samples share no rows. Therefore:

* **Sample-level integration is impossible.** MOFA+/MEFISTO, DIABLO and O2PLS all
  decompose blocks that share their rows. Feeding 48 rows (24 RNA + 24 protein) with
  NAs in the off-blocks does not integrate anything — the factors are unidentifiable
  across views and the output is an artefact.
* **The shared dimension is the design cell** (treatment × timepoint, 8 of them).
  Between-cell covariance — how the layers co-vary across treatment and time — is
  estimable and is the biology of interest.
* **Within-cell covariance is not estimable in Case B by any method.** Say so in the
  manuscript.

## Steps

| Step | Script | What it does |
|---|---|---|
| 00 | `R/00_simulate_data.R` | Ground-truth simulator. Two independent 24-sample sets from one shared latent biology; archetypes generated by *mechanism* (ODE rate constants), not by labelling. |
| 00b | `R/00b_check_simulation.R` | Asserts the simulator produces the biology it claims. Run after any change to 00. |
| 01 | `R/01_qc_normalise.R` | RNA: `filterByExpr` → VST (integration) + voom logCPM (DE). Protein: decoy/contaminant removal → unique-peptide filter → **"≥ n valid in ≥1 design cell"** → log2 → normalise. |
| 02 | `R/02_id_mapping.R` | Bipartite gene ↔ protein-group graph → connected components → Universe A (all features) and Universe B (clean 1:1 pairs). Detectability model for Tier-2 genes. |
| 03 | `R/03_missingness.R` | MNAR/MAR diagnosis and per-mechanism imputation, plus three sensitivity schemes. |
| 04 | `R/04_univariate_temporal_de.R` | limma for **both** layers (comparable effect sizes), 8-level cell design, per-timepoint + any-effect + interaction tests. Emits logFC **and moderated SE**. DESeq2 spline LRT cross-check. |
| 05 | `R/05_concordance_archetypes.R` | Kinetic null model + amplitude LRT → regulatory archetypes. Disattenuated concordance. Explicit identifiability accounting. |
| 06 | `R/06_integration_caseB.R` | Design-cell PLS, replicate bootstrap, **leave-one-cell-out Q² with permutation null**, replicate-pairing stability selection. |

Driver: `./run_all.sh` (add `--raw` once `data/raw/` is populated;
`--config config/config_prior.yaml` to enable the half-life prior).

## Three findings from the simulated run that change how you should analyse the real data

**1. Lag and regulation are confounded unless you model kinetics.**
Naive quadrant classification calls "RNA up, protein flat" post-transcriptional
repression. A protein with a long half-life shows exactly that pattern with no
regulation at all. Step 05 instead fits, per gene,

```
dp/dt = kd (r(t) - p(t)),  p(0) = 1          (M0, kinetics only)
logFC_prot(t) = a · log2 p(t; kd)            (M1, adds amplitude scaling a)
```

and tests M1 vs M0 by a 1-df LRT, weighted by each gene's moderated SE.
Validation on ground truth: **median a = 0.39 for truly buffered genes vs 0.97 for
truly concordant** — the estimator is unbiased. False-positive rate on unchanged
genes 0.3%.

**2. An external half-life prior is the highest-value thing you can add.**
With a 48 h course and ~12 h median half-lives, attenuation and slow turnover are
genuinely confounded for a large minority of genes. Those are reported as
`kinetics_limited` rather than silently called lag or buffering. Supplying published
turnover data via `concordance.half_life_prior_file`:

| | uninformed | with prior |
|---|---|---|
| regulated genes recovered | 27.1% | **72.1%** |
| unidentifiable (`kinetics_limited`) | 14.9% | **6.1%** |
| half-life recovery (Spearman) | 0.26 | **0.51** |
| true lag wrongly called regulated | 6.1% | 12.1% |
| true concordant wrongly called regulated | 8.9% | 14.6% |

The trade-off is real and belongs in a supplementary panel.

**3. In-sample cross-block correlation is worthless at 8 pseudo-samples.**
A PLS on 8 cells × thousands of features reaches r ≈ 0.96 — and reaches **r ≈ 0.72 on
permuted data**. Step 06 therefore reports leave-one-cell-out **Q²** against a
permutation null. On the simulated data: Q² = 0.26, permutation 95th percentile 0.03,
p = 0.01. That is the defensible statement of cross-omics coupling in Case B.

## Deliberate choices worth defending to a reviewer

* Protein validity filter is *"≥ n valid in at least one design cell"*, not a global
  ≥50% rule — the global rule deletes on/off biology. Complete-case would have kept
  188 of 1645 proteins.
* Imputed values are used for Universe A only. Universe B (concordance, kinetics)
  uses observed values. Imputing left-censored entries and then correlating RNA
  against protein manufactures anti-correlation and false regulation calls.
* Total least squares, not OLS, for the concordance slope — both axes carry error.
* Correlations are disattenuated for measurement error; with n=3 the raw correlation
  understates true coupling.
* limma for both layers so effect sizes are on the same scale.
* Never join on gene symbols (`SEPT7`, `MARCH1` → dates). Everything joins on stable
  accessions and Ensembl gene IDs.
* t0 acts as a built-in empirical null: no treatment effect exists there by design.

## Environment

```bash
Rscript env/install_r_deps.R          # CRAN + Bioconductor + timeOmics
Rscript env/install_r_deps.R core     # skip GitHub packages
```

Every script degrades gracefully when an optional package is missing and says which
fallback it used. Currently falling back: `imputeLCMD` (QRILC → down-shifted normal),
`MOFA2` (MEFISTO cross-check skipped).
